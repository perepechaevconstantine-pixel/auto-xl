# Инструкция по установке и запуску

Версия: act_analysis v2.9.9 (основная ветка: Общ_Сводная)
Назначение: анализ актов из сводных ГП с поддержкой столбца DP, устойчивой обработкой пропусков в списке актов и отображением данных по акту из Общей сводной даже если его нет в Сводной ГП.

## Состав папки

| Файл | Назначение |
|------|------------|
| `act_analysis.py` | Основной скрипт анализа актов |
| `install.bat` | Скрипт автоматической установки окружения и зависимостей |
| `requirements.txt` | Список необходимых Python-библиотек |
| `config.py` | Настройки путей к сетевым источникам (создаётся/редактируется при первом запуске) |
| `config.json` | Сохранённые пути к папкам с `.xlsb` источниками |
| `logs/` | Папка с логами запусков (создаётся автоматически) |

## Требования к компьютеру

- Windows 10 / Windows 11
- Установленный **Python 3.10+** (рекомендуется 3.11–3.13)
- Установленный **Microsoft Excel** (скрипт работает через `pywin32` COM)
- Сетевой доступ к папкам с исходными `.xlsb` файлами (пути настраиваются в `config.py`)

## Быстрая установка (один раз на каждый ПК)

1. Распакуйте архив с этой папкой в любое удобное место, например:
   ```
   D:\Рабочая папка\Анализ актов_ветка_Общ_Сводная\
   ```

2. Запустите `install.bat` двойным кликом или из командной строки:
   ```cmd
   cd /d D:\Путь\к\папке\Анализ актов_ветка_Общ_Сводная
   install.bat
   ```

   Скрипт:
   - создаст виртуальное окружение `.venv` рядом со скриптом;
   - установит все зависимости из `requirements.txt`;
   - проверит, что библиотеки импортируются без ошибок;
   - создаст папку `logs/` для логов.

3. Откройте файл `Анализ актов.xlsm` (или ваш файл с шаблоном анализа) в Excel.

4. На листе «Анализ»:
   - в ячейке **A1** укажите номер выполнения (например, `40`);
   - в столбце **B** со строки 3 перечислите акты (или нажмите кнопку «Пересобрать», чтобы скрипт собрал их сам);
   - вручную вставьте столбец **G** с заголовком `DP` между «КМ» и «Статусы» (если ещё не вставлен).

5. Запустите скрипт:
   ```cmd
   python act_analysis.py          — обновить цифры для текущего списка в B
   python act_analysis.py collect  — пересобрать список актов из сводных
   ```

   Или используйте кнопки макросов в Excel (`Кнопка_Обновить`, `Кнопка_Пересобрать`).

## Настройка путей к источникам

При первом запуске скрипт попросит указать сетевые папки с файлами:
- `Сводная_ГП_КМ_ПК1/2/3.xlsb` — источник ГП
- `ОБЩАЯ Сводная таблица по статусу объекта СПГ КМ (ПК1/2/3).xlsb` — общая сводная

Пути сохраняются в `config.json` и при последующих запусках используются автоматически.

## Ключевое отличие этой ветки

Скрипт отображает информацию по акту **вне зависимости от наличия его в Сводной ГП**:

| Акт в Сводной ГП | Акт в Общей сводной | Результат |
|------------------|---------------------|-----------|
| Есть | Есть | Данные из обоих источников |
| Нет | Есть | Данные из Общей сводной; поля ГП — нули, в столбце G «—», в статусе «(нет в Сводной ГП)» |
| Есть | Нет | Данные из Сводной ГП; поля Общей сводной — нули |
| Нет | Нет | Маркер «НЕ НАЙДЕНО» |

## Примечания

- Автоматический пересчёт в Excel отключён на время работы скрипта и не восстанавливается автоматически — пересчитайте формулы вручную после завершения.
- Фильтр ставится на строку 2 (заголовки), охватывает все столбцы с данными (до AB).
- Пустые строки в столбце B не получают порядкового номера в столбце A и не сдвигают остальные акты.
- При ошибке скрипт создаёт файл `last_error.txt` рядом с собой — пришлите его содержимое для диагностики.
